One two-part micro-confession, exactly as typed and never sent — a "To:" line naming who it was meant for, then the unsent message itself on a single line — written for make.fun's "Unsent: The Micro-Confession Sprint" bounty ($2 in USDC). A house judge reads confessions two at a time and picks the one that feels most genuinely unsent; this one keeps its reason for staying in drafts felt rather than stated, inside the 260-character gate (message line 160 characters, under the 200 cap).

## Run it

```sh
node main.ts
```

This writes the confession (172 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), then reads it back to confirm the round-trip.
